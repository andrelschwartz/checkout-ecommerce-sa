 Checkout E-commerce

 Descrição
Projeto desenvolvido em JavaScript para calcular o subtotal das compras, contar os itens do carrinho e aplicar cupons de desconto.

 Funcionalidades
- Cálculo do subtotal e quantidade de itens.
- Cupons DESC10, DESC20 e FRETEGRATIS.
- Finalização da compra com cálculo do desconto e total.

 Como executar
É necessário ter o Node.js instalado. No terminal, execute:

node checkout.js

 Versionamento
O Git foi utilizado para controlar as versões do código, com as branches main, develop, feature/carrinho-laco e feature/validacao-cupom.

 Como o Git evita problemas
O Git permite que desenvolvedores trabalhem em branches separadas, registrem alterações em commits e resolvam conflitos antes de integrar o código.
